# Pesquisa com usuários

Kit de **teste de usabilidade** do Guia Eleitor PR (evidência de qualidade/replicabilidade):

- `teste-usabilidade.html` — plano, roteiro de 8 tarefas, questionário **UEQ** (26 itens), termo de consentimento LGPD e ficha de coleta. Abra no navegador (ou imprima) para aplicar com 5–8 participantes.

Pontuação do UEQ: usar a planilha oficial gratuita em ueq-online.org (Data Analysis Tool).
Ao rodar, guardar aqui as fichas anônimas e um relatório-resumo (taxa de sucesso, SEQ, 6 dimensões do UEQ, problemas priorizados).
